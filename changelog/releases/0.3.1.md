## Why Care?

Searching Magnific's stock images from Image Gin had become slow enough to look broken. You'd search, and the results took long enough that it seemed nothing was happening.

It was doing far more than you asked. 0.3.1 makes it do only that.

## What's New?

- **Faster searches.** You get the number of results set in Image Gin's settings, 10 by default, instead of 50.
- **Less clutter in the plugin folder.** Image Gin caches a thumbnail for every result, so it now caches 10 instead of 50 per search.
- **Secure image links.** Magnific returns image addresses as `http://`. Image Gin now inserts them as `https://`, which serves the same files.

## What Went Wrong

Image Gin asked Magnific for results with `per_page`. Magnific's API takes `limit`, ignores `per_page`, and returns its default of 50. The search modal then downloaded a thumbnail for each of them before showing anything.

## Good to Know

- **Clear old thumbnails** with **Clear Cache** in Image Gin's settings, if earlier searches left a lot behind.
- **Requires Obsidian 1.13**, as 0.3.0 did.
- **Under the hood:** `src/services/magnificService.ts` sends `limit` and upgrades `image.source.url` to https. The thumbnail cache folder is now gitignored.
